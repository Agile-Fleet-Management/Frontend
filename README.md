🚗 Municipal Vehicle Management Dashboard – UI Showcase

This project is a front-end interface designed for managing vehicle missions, user requests, and maintenance schedules in a municipal context. It was built with a focus on usability, clean design, and dynamic component rendering.

🛠️ Front-End Tech Stack

✅ Frameworks & Libraries Used

Category	Framework/Library
Core Framework	React.js
Styling	Tailwind CSS
Component Library	Shadcn/UI, Headless UI
Icons	Lucide React
Charts & Graphs	Recharts
Routing & State	React Router, Zustand
Forms	React Hook Form + Zod
Maps Integration	Leaflet.js + OpenStreetMap


⸻

🧩 Key UI Features
	•	📊 Analytics Dashboard: Overview of vehicle usage, maintenance, and requests.
	•	🧾 Dynamic Forms: For scheduling, approvals, and tracking.
	•	🧍 User Management: Add, edit, delete users with role-based access.
	•	🚗 Vehicle View: Interactive list and map-based detail viewer.
	•	📍 Map Tracker: Real-time and historical vehicle tracking via OpenStreetMap.

⸻

🎯 Goals
	•	Deliver a clean, responsive, and accessible UI
	•	Integrate well with existing backend systems or APIs
	•	Modular and easily extendable architecture for municipalities
